# AI DS Server

Панель управления Discord-сервером, основной Discord-клиент и отдельные Python-боты для модерации, поддержки, экономики и креативов.

## Компоненты

- **Основной бот и панель** — Node.js, Discord.js, Express и SQLite. Основной бот управляет модулями сервера; веб-панель доступна локально.
- **Модератор** — наказания, очистка сообщений и учёт голосового времени.
- **Саппорт** — верификация, статистика команды, заявки на персонал, отпуск, трибунал и инструменты саппорта.
- **Экономика** — отдельный бот с валютой Chiil coin, балансами, переводами, ежедневной наградой и магазином ролей.
- **Креатив** — отдельный бот для анонсов, событий, профилей и передачи событий между участниками команды.

Данные панели хранятся в `data.db`, данные Python-ботов и экономики — в `shared_bot_data.db`. Не удаляйте эти файлы: в них находится рабочее состояние и история.

## Требования

- Windows или Linux
- Node.js и npm
- Python 3.10 или новее
- Discord-приложение и бот для каждого запускаемого бота

## Установка

```powershell
git clone https://github.com/BitStopSU/AI_DS_Server.git
cd AI_DS_Server
npm install
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В Linux активируйте окружение командой `source .venv/bin/activate` и создайте `.env` командой `cp .env.example .env`.

Заполните `.env` локально. Минимально для основного клиента нужны `DISCORD_TOKEN` и `GUILD_ID`. Токены отдельных ботов задаются через панель или переменные окружения:

- `SUPPORT_BOT_TOKEN`
- `MOD_BOT_TOKEN`
- `ECONOMY_BOT_TOKEN`
- `CREATIVE_BOT_TOKEN`

Для AI-функций заполните ключ выбранного провайдера, например `OPENAI_API_KEY`. Остальные значения конфигурации перечислены в `.env.example`.

> Не публикуйте `.env`, токены Discord, ключи ИИ или содержимое локальных баз данных. Если меняете `DISCORD_TOKEN`, повторно сохраните токены дочерних ботов: ключ шифрования сохранённых токенов зависит от основного токена.

## Запуск панели и основного бота

Активируйте Python-окружение, затем запустите проект:

```powershell
npm start
```

Панель открывается на `http://localhost:4477` и привязана к `127.0.0.1`. Не выставляйте её в локальную сеть или интернет: API панели не имеет полноценной авторизации.

В разделе **Боты** можно сохранить отдельный токен, задать автозапуск, запустить, остановить и перезапустить зарегистрированных ботов. Экономика и креатив добавляются в панель с выключенным автозапуском. Пока токен не задан, они остаются остановленными.

## Команды экономики

Отдельный бот экономики использует валюту **Chiil coin**. Основные команды:

- `/balance` — проверить свой или выбранного участника баланс.
- `/daily` — забрать ежедневную награду.
- `/give` — перевести монеты другому участнику.
- `/profile` — показать карточку профиля с балансом и статистикой.
- `/top` — рейтинг по балансу.
- `/transactions` — последние операции.
- `/shop` — список продаваемых ролей.
- `/shop-buy` — купить роль из магазина.
- `/shop-add` и `/shop-remove` — настроить ассортимент магазина.
- `/economy-add` — начислить монеты участнику.

Настройка магазина и начисления ограничены серверными правами администратора и проверками в обработчиках команд. Для выдачи ролей поднимите роль экономического бота выше ролей, которые продаются.

## Команды креативов

Команды находятся в группе `/creative`:

- `/afisha` — опубликовать анонс мероприятия.
- `/creative action` — добавить или убрать участника из команды креативов.
- `/creative manage` — создать событие.
- `/creative profile` — показать профиль креатива.
- `/creative stats` — показать статистику событий.
- `/creative transfer` — передать событие другому креативу.

Управление составом креативов доступно администраторам сервера. Участники могут управлять собственными событиями в соответствии с проверками доступа.

## Саппорт, трибунал и набор персонала

Бот саппорта включает, помимо существующих `/verf`, `/unverify`, `/duty`, `/myweek`, `/weekreport`, `/note`, `/history` и профилей, команды из новых модулей:

- **Команда саппорта:** `/swarn`, `/teststats`, `/addtwink`, `/twinks`, `/vacation`, `/vacations`, `/alltop`, `/gtop`, `/smistakeadd`, `/smistakes`, `/sadd`, `/slist`, `/sprofile`, `/spkmadd`, `/spkmlink`, `/spkmrem`, `/pkmstats`, `/ptstats`, `/slinktg`, `/slink`, `/spcheck`, `/sedprofile`, `/smpanel`, `/squest`, `/nedo`, `/unnedo`, `/uwu` и `/cornsgive`.
- **Трибунал:** `/tadd`, `/tedit`, `/tlist`, `/tprofedit`, `/tprofile`, `/tquest`, `/tquestadd`, `/tquestmanage`, `/trem`, `/tshop`, `/tshopadd`, `/tshopmanage`, `/tstatus`, `/ttribuna`, `/ttribunes` и `/twarn`.
- **Набор:** `/recruit_post` публикует карточку с открытыми ролями, встроенным баннером и меню выбора направления; `/vacancy-send` публикует карточку в текущий канал. Дополнительно доступны `/vacancy-blacklist`, `/vacancy-schedule` и `/vacancy-settings`.

Открытые направления, канал публикации и каналы рассмотрения заявок настраиваются во вкладке **Набор персонала** веб-панели. Баннер можно заменить URL изображения в настройке набора; если URL не задан, используется `public/recruitment-banner.png`.

## Discord Developer Portal

Пригласите каждого отдельного бота на сервер и назначьте ему необходимые права. Бот экономики и бот креативов используют slash-команды и не требуют privileged member intent. Саппорт-бот также не запрашивает `Server Members Intent`; предупреждение `Message Content Intent is missing` относится к обычным текстовым сообщениям, но не отключает slash-команды. Для функций, работающих с голосовыми каналами, нужны разрешения и intent голосовых состояний.

После входа бота в Discord slash-команды синхронизируются. Если новая команда не отображается, перезапустите соответствующего бота и проверьте его лог в панели.

## Структура проекта

- `index.js` — основной Discord-клиент и запуск локальной панели.
- `web/` — Express API.
- `public/preview.html` — интерфейс панели.
- `core/` — процессы, настройки и шифрование токенов.
- `modules/` — модули Discord-сервера.
- `bots/support_bot.py` — бот саппорта и набор персонала.
- `bots/mod_bot.py` — бот модерации.
- `bots/economy_bot.py` — экономика Chiil coin.
- `bots/creative_bot.py` — события и команда креативов.
- `bots/support_features.py` и `bots/tribunal_features.py` — дополнительные функции саппорта и трибунала.
- `db/` — схема и инициализация базы панели.

## Проверки перед развёртыванием

```powershell
node --check index.js
python -m py_compile bots\support_bot.py bots\support_features.py bots\tribunal_features.py bots\economy_bot.py bots\creative_bot.py
```

Затем проверьте в панели `/api/bots`, откройте логи каждого бота и убедитесь, что он подключён к Discord. Для экономики и креативов дополнительно настройте их отдельные токены перед запуском.
