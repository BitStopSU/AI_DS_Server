# AI DS Server

Discord-система для управления персоналом, модерацией, верификацией и AI-помощником.

Проект состоит из основной Node.js-панели и двух отдельных Python-ботов:

- **Саппорт** — верификация участников, профили персонала, статистика и набор заявок.
- **Модератор** — предупреждения, муты, кики, баны и очистка сообщений.
- **AI-бот** — управление Discord-сервером через веб-панель.

## Возможности

- Веб-панель управления ботами, ролями и командами.
- Автоматическая выдача роли `unverify` новым участникам.
- Команды верификации и модерации через slash-команды Discord.
- Привязка команд к категориям ролей.
- Статистика верификаций, наказаний и времени персонала.
- Команда структуры персонала по веткам.
- Система набора саппортов и модераторов с отдельными каналами заявок.
- Праздничное оформление названий каналов в категориях сервера.
- Бекапы сервера с поддержкой локального хранилища и Яндекс.Диска.

## Требования

- Windows или Linux
- Node.js 22+
- Python 3.12+
- SQLite
- Discord-приложения для основного, саппорт- и модератор-ботов

## Установка

```powershell
git clone https://github.com/BitStopSU/AI_DS_Server.git
cd AI_DS_Server
npm install
python -m pip install -r requirements.txt
```

Создайте `.env` на основе `.env.example`:

```env
DISCORD_TOKEN=
GUILD_ID=
PORT=4477
SUPPORT_BOT_TOKEN=
MOD_BOT_TOKEN=
ANTHROPIC_API_KEY=
OPENAI_API_KEY=
```

В Discord Developer Portal включите для ботов, которым нужны участники и роли:

- `Server Members Intent`
- `Message Content Intent`, если используются текстовые команды
- `Voice States Intent`, если используется учёт времени в голосовых каналах

## Запуск

```powershell
npm start
```

Панель доступна по адресу:

```text
http://localhost:4477
```

В разделе **Боты** можно запустить, остановить или перезапустить:

- Саппорт
- Модератор

## Основные команды

### Саппорт

- `/verf` — провести верификацию участника.
- `/staf_profile` — показать профиль сотрудника.
- `/staf_stats` — показать общую статистику персонала.
- `/top_veref` или `/top_verf` — показать топ саппортов.
- `/stafftable` — показать структуру персонала.
- `/recruit_post` — опубликовать набор на сервере.

### Модератор

- `/achen` — применить предупреждение, мут, кик или бан.
- `/clear` — удалить сообщения в канале.

Доступ к командам можно настроить во вкладке **Роли и команды**.

## Структура проекта

- `index.js` — основной Discord-клиент и запуск панели.
- `web/` — Express-сервер и веб-интерфейс.
- `core/` — процессы, модули, настройки и шифрование токенов.
- `modules/` — модули сервера.
- `bots/` — Python-боты саппорта и модерации.
- `db/` — SQLite-схема и инициализация базы.
- `public/` — веб-панель управления.
- `shared_bot_data.db` — локальная база статистики ботов.
- `data.db` — база панели и настроек.

## Безопасность

Не публикуйте `.env`, токены Discord или API-ключи ИИ в репозитории.
